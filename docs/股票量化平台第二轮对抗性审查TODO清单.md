## 0. 总结、边界和执行原则

当前平台应定位为：

> 工程闭环较完整的个人 A 股规则多因子研究和前向模拟平台；尚不是已验证
> Alpha 的策略，也不是可接入真实资金的生产级量化交易系统。

正式版本 7 的留出集绝对收益为 `9.548774%`、Sharpe 为 `0.471736`、最大
回撤为 `-17.4844%`，但同口径等权基准收益约为 `28.3577%`，策略超额收益约
为 `-18.809` 个百分点，主动 Sharpe 约为 `-1.287`。留出期 Rank IC 均值约
为 `0.03086`，Newey-West t 值约为 `1.256`、p 值约为 `0.209`，五档收益不
单调。因此当前证据只证明链路可以运行，不能证明策略具有可投资 Alpha。

执行本文时遵守以下原则：

- 不允许通过降低数据、收益、风险或统计门槛让旧版本“通过”。
- 任何影响研究口径的修改必须创建新策略版本，旧版本和旧证据保持不可变。
- 每一项修复必须同时包含正常路径、异常路径、历史边界和失败降级测试。
- 两个月模拟盘只验收运行链路，不作为策略有效性或实盘批准的充分条件。
- 在 P0 全部完成前，版本 7 必须保持 `paper` 或转为明确的
  `paper_operational_validation`，不得进入 `approved/live`。

## P0-A：策略有效性与生命周期硬门禁

- [x] **QAR-001 纠正“流程通过等于策略有效”的生命周期语义**
  - 现状：`validated` 只要求数据覆盖、一次留出、至少三折及 Sharpe 非空；
    即使 Sharpe 为负或严重跑输基准也能晋级。
  - 风险：无 Alpha 的策略可能依靠完整实验快照和流程证据进入模拟或实盘审批。
  - [x] 将“运行链路验证”和“投资有效性验证”拆成独立状态或独立门禁。
  - [x] 要求投资有效性证据必须包含净超额收益、主动 Sharpe/IR、回撤、
    IC 显著性、分层单调性和成本压力结果。
  - [x] 为每个门禁保存阈值、实际值、通过状态、证据哈希和拒绝原因。
  - [x] 验收：构造 `holdout_sharpe=-1`、超额收益为负、IC 不显著的证据，
    系统必须拒绝进入投资有效性 validated 状态。

- [x] **QAR-002 将版本 7 明确限制为运行链路模拟版本**
  - 现状：版本 7 状态为 `paper`，但其正式留出期大幅跑输等权基准。
  - 风险：页面或后续操作者可能把 `paper` 理解为已经通过 Alpha 验证。
  - [x] 在版本参数、API 和页面同时显示“仅验证数据/调度/成交/账本运行”。
  - [x] 在版本 7 上设置不可绕过的 `approved/live` 阻断原因。
  - [x] 只有新版本通过本文策略有效性门禁后才能解除阻断。
  - [x] 验收：直接调用状态迁移接口也无法把版本 7 提升到 approved。

- [x] **QAR-003 把正式样本外基准和主动指标纳入冻结证据**
  - 现状：验证结果只冻结总收益、Sharpe、回撤、换手、费用和覆盖率。
  - 风险：只看绝对收益会把牛市 Beta 误认为选股能力。
  - [x] 保存基准类型、基准代码、基准收益、超额收益、跟踪误差、主动
    Sharpe/信息比率、Alpha/Beta 和上/下行捕获率。
  - [x] 指标必须由与策略同日历、同起算时点的曲线直接计算。
  - [x] 验收：篡改基准代码、基准曲线或基准起算日都会改变证据哈希并阻止晋级。

- [x] **QAR-004 建立明确的投资任务书（Investment Mandate）**
  - 现状：已有股票池、Top N 和部分风险参数，但缺少完整的投资政策定义。
  - 风险：无法判断一个结果究竟是成功、失败还是偏离了最初目标。
  - [x] 固化目标投资者、资金规模、投资期限、调仓频率、基准、收益目标。
  - [x] 固化最大回撤、波动、跟踪误差、换手、行业/风格偏离和流动性预算。
  - [x] 固化允许证券、禁止证券、现金范围、停牌/退市和异常行情政策。
  - [x] 固化策略停止、降仓、退休和重新验证条件。
  - [x] 验收：每个策略版本都必须绑定不可变 mandate 版本及其哈希。

- [x] **QAR-005 定义可审计的策略有效性最低标准**
  - 现状：没有正超额收益、主动风险和统计显著性的最低标准。
  - 风险：审批结果依赖人工主观解释。
  - [x] 由项目策略政策明确最低净超额收益和最低主动 Sharpe/IR。
  - [x] 明确最大允许回撤、最差年度/行情状态、成本翻倍后的最低结果。
  - [x] 明确 IC、ICIR、置信区间和分层单调性的最低要求。
  - [x] 明确 PBO、DSR/PSR 和多重检验后的最低要求。
  - [x] 验收：门禁规则版本化，历史版本可以复现当时使用的全部阈值。

- [x] **QAR-006 区分两个月运行验收与收益有效性验收**
  - 现状：两个月模拟盘容易被误用为收益验证。
  - 风险：约 42 个交易日无法覆盖足够多的市场状态或月度信号。
  - [x] 两个月报告只评价数据准时率、信号一致性、订单、成交、账本、对账、
    告警和恢复。
  - [x] 收益报告必须显式标记样本量不足，不允许给出“策略有效”结论。
  - [x] 策略有效性继续使用多年样本外和更长期前向记录。
  - [x] 验收：即使两个月盈利，系统也不会自动触发 approved/live。

## P0-B：基准定义与正式验证证据

- [x] **QAR-007 修复正式版本未使用官方指数基准的问题**
  - 现状：正式 `BacktestConfig` 未设置 `benchmark_index`，结果回退为
    universe 等权买入持有。
  - 风险：实际证据与原修复清单“优先含分红中证800或权重合成基准”不一致。
  - [x] 接入并验证中证800全收益指数或可严格复现的 300+500全收益权重基准。
  - [x] 基准数据必须覆盖正式验证全部日期并有来源、版本和哈希。
  - [x] 禁止正式验证静默回退；基准不可用时必须失败。
  - [x] 验收：版本证据中的 `benchmark_kind` 必须是明确官方基准而非
    `equal_weight`。

- [x] **QAR-008 同时保留多种可投资替代基准**
  - 现状：单一等权基准不足以解释收益来源。
  - 风险：策略可能只是在承担小盘、低波或行业偏离。
  - [x] 同时计算官方市值权重全收益基准、同股票池等权基准、无风险/现金基准。
  - [x] 可选增加低波、价值、质量等透明风格基准用于归因。
  - [x] 所有基准使用同一可成交起点、同一日历和明确的分红处理。
  - [x] 验收：正式报告逐一展示绝对收益和相对各基准的主动指标。

- [x] **QAR-009 建立动态指数成分权重而不仅是动态成员**
  - 现状：历史动态成员已接入，但组合行业基准主要依赖自由流通市值近似。
  - 风险：无法严格复现指数的历史行业和个股权重。
  - [x] 保存每期官方指数成员权重及其公告/生效日期。
  - [x] 对 300 和 500 合成权重定义固定、可复现的合成方法。
  - [x] 对权重缺失、权重和不为 100%、临时调整建立阻断规则。
  - [x] 验收：任意历史信号日都能查询使用的逐股基准权重和源文件哈希。

- [ ] **QAR-010 重新生成包含基准和主动统计的正式证据**
  - 现状：版本 7 冻结证据无法回答是否跑赢基准。
  - 风险：继续引用旧证据会重复错误结论。
  - [ ] 修复基准和验证统计后创建新策略版本，不覆盖版本 7。
  - [ ] 对训练、验证、留出、年度和行情状态输出统一主动指标。
  - [ ] 保存旧证据与新证据差异说明。
  - [ ] 验收：新版本报告可从原始净值曲线独立复算全部主动指标。
  - 外部证据缺口：当前修复工作区尚未形成用户确认的干净提交，按留出集防污染
    门禁不能创建新正式版本；不得在此处用临时/脏代码结果冒充冻结证据。

## P0-C：回测和成交真实性

- [x] **QAR-011 消除“开盘成交使用当天全日成交量”的未来数据**
  - 现状：T+1 使用开盘价成交，但容量使用 T+1 完整日成交量。
  - 风险：开盘时无法知道全天成交量，会高估可成交数量并扭曲冲击成本。
  - [x] 选择并固化一种一致模型：集合竞价/开盘模型，或日内 VWAP/TWAP 模型。
  - [x] 开盘模型只能使用开盘前可知 ADV、集合竞价量、盘口和开盘成交量。
  - [x] VWAP/TWAP 模型必须使用日内 bar、成交量曲线和相应成交价格。
  - [x] 回测与前向模拟共用同一容量和价格模型。
  - [x] 验收：修改成交日收盘后的成交量不能改变开盘成交结果。

- [x] **QAR-012 实现按市场、板块和日期变化的申报数量规则**
  - 现状：全部股票买入统一按 100 股整数倍。
  - 风险：科创板最低 200 股且超过后可按 1 股递增，当前可能生成非法订单。
  - [x] 建立交易规则表：交易所、板块、生效日期、最低申报量、递增单位、
    最大申报量和零股卖出规则。
  - [x] 覆盖沪深主板、创业板、科创板、北交所及规则变更历史。
  - [x] OMS、回测、前向模拟和组合成交后修正必须共用同一规则服务。
  - [x] 验收：科创板 100 股买单被拒绝，200/201 股按对应订单类型正确处理。

- [x] **QAR-013 实现日期时变的印花税和交易费用**
  - 现状：2020～2026 全区间固定使用卖出 0.05% 印花税。
  - 风险：低估 2023-08-28 以前的成本，导致历史净收益偏高。
  - [x] 建立按证券、市场、方向和生效日期查询的费率表。
  - [x] 覆盖印花税变更、佣金、最低佣金、过户费及其他适用费用。
  - [x] 保存每笔成交实际使用的费用规则版本。
  - [x] 验收：变更日前后同金额卖出的税费符合各自历史政策。

- [x] **QAR-014 实现历史时变涨跌停与 IPO 特殊规则**
  - 现状：权威 `stk_limit` 缺失时按当前板块规则回退，没有历史生效日期。
  - 风险：创业板改革前、IPO 前若干日和退市整理期可能被错误判定为可成交。
  - [x] 建立按板块、证券状态和日期变化的涨跌幅规则。
  - [x] 覆盖 IPO 无涨跌停期、创业板改革切换、科创板、北交所、ST 和退市整理期。
  - [x] 正式验证对 `stk_limit` 缺失设置覆盖率门禁，不允许大量依赖回退。
  - [x] 验收：对每个规则边界日前后设置黄金测试案例。

- [x] **QAR-015 建立严格的 A 股 T+1 可卖持仓批次账本**
  - 现状：持仓只保存总股数，没有买入日期和当日可卖数量。
  - 风险：在调仓覆盖、公司行为或未来提高调仓频率时可能发生当日买入当日卖出。
  - [x] 按成交批次记录获得日期、可卖日期、成本和公司行为来源。
  - [x] 卖出只使用已经结算并可卖的股份。
  - [x] OMS/RMS、回测、前向和对账使用同一可卖口径。
  - [x] 验收：同日买入后的卖单被拒绝或延后，下一交易日正确释放。

- [x] **QAR-016 修复开盘价缺失时回退当日收盘价的时点冲突**
  - 现状：开盘价缺失时可能使用当日收盘价作为成交价。
  - 风险：以收盘后才确定的价格模拟开盘成交，形成隐性未来数据。
  - [x] 开盘策略遇开盘价缺失时明确拒绝、顺延或切换到已定义的日内执行策略。
  - [x] 禁止在未改变成交时间语义时直接回退收盘价。
  - [x] 验收：开盘价缺失案例不会产生标记为“开盘成交”的收盘价成交。

- [x] **QAR-017 建立真实可校准的滑点和市场冲击模型**
  - 现状：固定滑点、平方根参与率和波动拖累使用经验常数。
  - 风险：回测净收益对未经验证的常数高度敏感。
  - [x] 保存 arrival price、决策价、成交均价、VWAP、参与率和实现损失。
  - [x] 按板块、流动性、波动、订单方向、规模和时段校准参数。
  - [x] 建立基准、乐观、保守和极端成本情景。
  - [x] 验收：前向模拟/实盘成交能够周期性反哺参数并输出校准误差。

- [x] **QAR-018 完善未成交订单的机会成本和时效**
  - 现状：被阻塞订单会顺延重试，主要在下一调仓目标到来时覆盖。
  - 风险：长期停牌或连续涨跌停订单可能无限存续，忽略信号衰减和机会成本。
  - [x] 定义订单 TTL、最大重试日、信号衰减、价格偏离和取消条件。
  - [x] 对部分成交、过期、覆盖和人工取消计算机会成本。
  - [x] 验收：长期无法成交的订单在确定时间退出，并有明确审计原因。

- [x] **QAR-019 现金收益和资金可用性建模**
  - 现状：未投资现金基本按零收益处理。
  - 风险：现金比例较高时与真实账户资金收益、资金冻结和费用扣款不一致。
  - [x] 明确现金是否计息、使用何种无风险曲线及何时入账。
  - [x] 区分可用、冻结、应收和已结算现金。
  - [x] 验收：现金、应收股息、冻结买单资金和费用在每日账本中严格守恒。

## P0-D：公司行为、退市和税务

- [x] **QAR-020 修复退市证券按最后收盘价自动清算**
  - 现状：正式退市日或名称含“退”的证券可能按最后可见收盘价结清。
  - 风险：最后交易价格不等于最终清算、现金选择权或换股对价，可能高估回收。
  - [x] 按退市类型区分现金清算、转板、换股、破产、长期冻结和未知。
  - [x] 未知最终对价时不得自动确认现金收益，应保留受限资产并使用保守估值。
  - [x] 建立人工核对和后续更正流程。
  - [x] 验收：缺少官方对价的退市不会按最后收盘价自动变现。

- [x] **QAR-021 完善个人投资者股息红利税**
  - 现状：主要使用源数据 `cash_div_tax/cash_div`，没有按账户持有期限动态计税。
  - 风险：真实个人账户税负取决于持有期，并常在卖出时追缴。
  - [x] 按 FIFO 持仓批次计算一个月内、一个月至一年和一年以上的税务状态。
  - [x] 建模派息时暂扣和卖出时补扣/追缴。
  - [x] 规则按政策生效日期版本化。
  - [x] 验收：不同持有期限的相同分红产生正确最终净现金。

- [x] **QAR-022 完善配股决策和配股权价值**
  - 现状：配股倾向于在现金允许时尽量认购。
  - 风险：忽略不认购、部分认购、配股权可交易和现金优先级。
  - [x] 明确策略的配股决策规则和资金保留顺序。
  - [x] 处理部分认购、认购失败、配股权出售或失效。
  - [x] 验收：现金不足和不同决策规则下的权益变化可复现。

- [x] **QAR-023 完善换股、合并、拆并股和零碎股处理**
  - 现状：通用事件支持换股和送转，但零碎股、尾差和现金补偿不完整。
  - 风险：持仓可能出现券商无法实际登记的股份数量或遗漏现金补偿。
  - [x] 建立每种市场事件的份额取整、零碎股处置、补偿和生效/到账日期规则。
  - [x] 对换股后新证券上市前设置受限状态。
  - [x] 验收：事件前后总经济权益在允许误差内守恒。

- [x] **QAR-024 建立完整、持续更新的公司行为主数据**

## P1-C：横截面处理、Alpha 预测和因子研究

- [x] **QAR-045 用横截面 WLS 残差化替代仅行业内标准化**

  - 风险：因子收益可能实质来自未控制的风格暴露。
  - [x] 每期用行业哑变量、log 市值、Beta、流动性等做加权横截面回归。
  - [x] 使用自由流通市值或稳健权重，并处理共线性和小行业。
  - [x] 保存原始因子、回归系数、残差和解释度。
  - [x] 验收：中性化因子与控制变量的加权相关接近零。

- [x] **QAR-046 用外部可投资市场/因子模型计算 Beta 和残差**
  - 现状：市场代理为当前 universe 的等权收益，且包含股票自身。
  - 风险：自包含和股票池变化会污染 Beta、残差波动和残差动量。
  - [x] 使用官方市场全收益指数，或严格构造不含自身的市场代理。
  - [x] 评估 CAPM、行业+市场或多因子残差模型。
  - [x] 保存窗口、缺失处理和回归诊断。
  - [x] 验收：单只股票自身收益的变化不会机械改变其市场代理。

- [x] **QAR-047 检查并治理动量、趋势和低波因子冗余**
  - 现状：12-1、6-1、残差动量、趋势和多种低波指标可能高度相关。
  - 风险：固定族权重不能阻止重复押注同一种风险。
  - [x] 每期和滚动窗口输出因子相关、VIF、边际 IC 和条件 IC。
  - [x] 对高度相关因子做正交化、聚类合成或删除。
  - [x] 验收：每个保留因子在控制其他因子后仍有稳定边际信息。

- [x] **QAR-048 用滚动收缩 IC 权重替代固定 30/25/20/15/10**
  - 现状：因子族权重为人工固定值，没有利用历史预测能力。
  - 风险：失效因子继续占据权重，偶然强势因子又可能被过度追逐。
  - [x] 仅使用训练窗口估计滚动 Rank IC/收益方向。
  - [x] 对权重做指数衰减、贝叶斯/James-Stein 收缩和上限约束。
  - [x] 权重默认向零或稳健先验收缩，而不是无条件满额分配。
  - [x] 验收：未来收益不参与权重，权重历史可复现并具备稳定性报告。

- [x] **QAR-049 建立 Ridge/Elastic-Net 横截面收益预测基线**
  - 现状：当前模型只是固定因子线性加权，不是真正训练的预测模型。
  - 风险：无法估计因子边际贡献、交互后的有效性或系数不确定性。
  - [x] 目标定义为下一持有期相对基准/行业的残差收益。
  - [x] 使用滚动时间窗口、标准化、行业/时间固定效应和正则化。
  - [x] 超参数只能在训练段嵌套选择。
  - [x] 输出预测值、系数、稳定性和校准曲线。
  - [x] 验收：与固定权重模型进行完全同口径样本外 challenger 对比。

- [x] **QAR-050 将 LightGBM/XGBoost 排序模型仅作为 challenger**
  - 现状：尚无非线性模型；有效月度样本期数仍有限。
  - 风险：直接用复杂模型会放大过拟合和数据泄漏。
  - [x] 在完成 PIT、嵌套验证和实验注册后再加入树模型。
  - [x] 使用时间切分、横截面 rank/回归目标和严格早停。
  - [x] 与 Ridge、IC 加权和简单等权基线比较净超额收益。
  - [x] 验收：复杂模型只有在多个独立样本外窗口稳定胜出后才可成为 champion。

- [x] **QAR-051 将 IPCA/隐含因子模型限制为研究 challenger**
  - 现状：风险和预期收益都依赖人工因子，没有时变隐含风险结构。
  - 风险：过早把高维隐含模型用于生产会降低可解释性和稳定性。
  - [x] 先研究 IPCA 是否能更好解释横截面协方差和时变载荷。
  - [x] 与显式行业/风格风险模型比较样本外解释力。
  - [x] 验收：只有数据量、稳定性和风险解释均达标后才进入组合层。

- [x] **QAR-052 暂不把深度学习或强化学习作为核心 Alpha**
  - 现状：用户已决定现阶段以规则策略为主；当前模拟器和 Alpha 证据仍不稳定。
  - 风险：RL 会优先学习模拟器误差，深度模型会放大有限时间样本的过拟合。
  - [x] 在治理文档中明确核心 Alpha 暂不采用 RL/深度网络。
  - [x] 如未来研究 RL，先限定在执行或 contextual bandit，并与无 RL 基线比较。
