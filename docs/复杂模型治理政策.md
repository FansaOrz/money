# 复杂模型治理政策

## 当前生产边界

- 当前 champion 仅允许可解释的规则多因子、滚动收缩 IC 权重，以及通过独立审查后的线性正则化模型。
- 深度神经网络和强化学习不得作为当前核心 Alpha、仓位决策或风险限额的生产来源。
- XGBoost/LightGBM、IPCA 仅属于 challenger；研究结果不能直接改变模拟盘或实盘订单。
- 任何 challenger 必须先完成 PIT 数据、嵌套时间验证、实验预注册、模拟器有效性、多个独立样本外窗口和模型风险复核。

## 后续研究边界

- 强化学习若启动研究，优先限制于最优执行或有明确安全动作集合的 contextual bandit；不得绕过 OMS/RMS、价格限制、现金、T+1、容量和 kill switch。
- 每个 RL/深度模型必须与无 RL 的 TWAP/VWAP/冲击模型、规则 Alpha、Ridge 和收缩 IC 基线按完全相同数据、成本与样本外窗口比较。
- 奖励函数、状态、动作、模拟器误差、离线策略评估和安全约束必须预注册；模拟器真实性未通过时不得解释收益改进。
- 复杂模型即使样本外胜出，也只能进入独立模型风险审查，不能自动晋升 champion。

## 放行原则

复杂度本身不是收益证据。只有净超额、稳定性、容量、尾部风险、可解释性和运维可控性同时优于简单基线，且结果可复现，才允许提出生产变更申请。
