# 股票规则策略版本 8 历史验证报告

日期：2026-08-05

## 结论

版本 8 的历史验证流程已完整执行并保留证据，但策略验证失败，已审计退役；
没有启动两个月前向账户，也不具备投资有效性。

最关键的失败不是单纯跑输基准，而是训练折、验证集和留出集的换手率、费用
均为零。策略全程持有计息现金，没有产生股票成交。因此：

- 系统机械选出的 `top_n=24`、`max_stock_weight=0.04` 没有参数意义；
- `+2.41%` 的留出收益来自现金利息，不是股票 Alpha；
- 六组参数的折外结果近乎完全相关，不能证明参数选择有效；
- 本版本只证明历史数据和回测程序能够完成运行，不能证明选股策略有效；
- 版本 8 应退役，修复无目标/无成交根因后创建全新的策略版本；
- 已查看的留出区间永久作废，不得被后续版本重新声明为 pristine。

## 失败门禁

- 主动 Alpha：失败；主动收益置信区间下界为 `-0.2445%`（日频口径）。
- 五档单调性：失败；头尾档差的 95% 区间下界为 `-1.2588%`。
- 因子 IC：证据不足；Rank IC、ICIR 和显著性均为空。
- 稳定性：失败；最差年度超额收益为 `-28.15%`。
- 稳健性：失败；基线超额收益为负，且尚未执行 2x/3x 成本、容量、
  信号延迟和参数/数据扰动全目录。
- 交易链路：失败；留出集没有目标持仓、换手或成交。

## 运行中发现并修复的问题

1. 留出登记原来只拦截完全相同区间，现已改为任意日期重叠即阻断。
2. 接口原来无法从已运行版本显式派生新研究版本，现增加
   `create_new_version`。
3. 历史验证原来与当前行情 readiness 强耦合，现可保存历史证据，但 readiness
   未通过时绝不创建前向账户。
4. 长期停牌导致的陈旧行情/估值原来被误报为完全缺数，现区分“已知但不可交易”
   与“根本无数据”；实际选股和成交层仍排除停牌股票。
5. 运行门禁原来只要求有限 Sharpe，没有要求真实成交。现新增
   `holdout_trade_count >= 1` 和 `holdout_turnover > 0` 两项硬门禁，现金空跑
   不能再晋级。

失败实验 2、3 及其错误均保留在不可删除实验账本中；两次失败发生在训练折，
未查看留出集。

## 当前阻断和下一版本要求

当前数据 readiness 仍阻断前向账户：

- `stk_limit` SLA 为 degraded，安全动作是 `reduce_only`；
- 跨源复核存在 901 个未解决阻断，安全动作是 `halt_new_orders`；
- 行业主源与备用源使用不同分类层级，不能把分类名称不一致直接当成同口径冲突；
- 部分财务 ROE 存在单位/期间口径差异，需要统一后再复核。

版本 9 之前至少必须完成：

- 找出版本 8 无目标持仓的首个过滤环节，输出每个信号日逐层剩余股票数；
- 为“无可用因子、优化器不可行、离散化失败、成交阻断”分别设置硬失败；
- 在训练期内确认每折都有非空目标、真实模拟成交、非零换手和费用；
- 完成成本、容量、信号延迟、参数邻域、删期、删行业和数据延迟扰动；
- 创建全新策略版本和全新未重叠留出区间，不能再次使用
  `2018-10-23 ～ 2019-12-31` 或 `2025-04-10 ～ 2026-07-31`；
- readiness 全部恢复后，才允许创建两个月前向账户。
