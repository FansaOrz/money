> 目标：把当前“规则量化研究原型”升级为结果可复现、回测可信、前向模拟

## P0：结果正确性（正式测试前必须完成）

- [x] **QF-001 估值时点化**
  - PE/PB 按独立交易日序列保存和读取，不再把数据库最新估值附到所有财报。
  - 每个信号日只能使用 `trade_date <= signal_date` 的最后一条估值。
  - 自身历史估值分位由真实历史估值观测计算。
  - 验收：篡改信号日后的估值不改变历史信号；同一股票跨期 EP/BP 可变化。

- [x] **QF-002 修正 12-1 动量窗口**
  - 统一为 `P[T-21] / P[T-252] - 1`，最少需要 253 个交易日观测。
  - `MIN_HISTORY_DAYS` 与实际窗口保持一致。
  - 验收：最近 21 日价格变化不影响因子，T-252 以前数据不参与。

- [x] **QF-003 历史动态指数股票池接入回测**
  - 每个信号日使用当时的沪深300+中证500成分，不使用当前800只回放历史。
  - 自定义 `candidate_codes` 与动态指数股票池互斥且口径明确。
  - 股票池来源、快照日期和缺失成员进入回测 warning/结果元数据。
  - 验收：调入前不入池、调出后不入池；不得静默回退到当前成分。

- [x] **QF-004 历史退出成分数据覆盖门禁**
  - 补齐或明确限制历史退出成分的日线、财务、估值、行业、名称/ST 数据。
  - 回测前输出逐期覆盖率；低于门槛的区间拒绝运行，不用缺失股票“凑回测”。
  - 验收：每期股票池覆盖率可查询、可审计。

- [x] **QF-005 清理错误文档与降级语义**
  - 文档不得声称尚未接入的能力已经生效。
  - 所有数据降级在 API 和页面显式展示，禁止静默改变研究口径。

## P1：回测与前向模拟一致性

- [x] **QF-006 A股整手和现金约束统一**
  - 回测与前向模拟均按买入100股一手、卖出允许零股清仓的规则执行。
  - 先卖后买、最低佣金、现金不足递减一手的逻辑共用同一执行函数。

- [x] **QF-007 信号日边界统一**
  - 默认只在真实月末生成信号；区间起点不再隐式强制建仓。
  - 如需“起点建仓”，必须作为显式参数并写入策略版本。

- [x] **QF-008 基准统一**
  - 回测和前向模拟使用同一基准定义、同一起算时点和同一缺失处理。
  - 优先使用含分红的中证800或沪深300+中证500权重合成基准。
  - 策略尚未可成交时，基准不得提前计入收益。

- [x] **QF-009 真实交易日历接入**
  - 使用已下载 `trade_cal`，不再从前50只股票行情推断交易日。
  - 休市、临时停市和数据缺口必须能区分。

- [x] **QF-010 真实停牌及涨跌停数据接入**
  - `suspend_d`、`stk_limit` 作为主判断，OHLC/涨跌幅推断仅作回退并告警。

- [x] **QF-011 公司行为与退市处理**
  - 分红现金、送转拆并股、配股、退市、合并、现金收购进入持仓和净值。
  - 研究收益使用复权价，执行和持仓使用原始价加公司行为事件。

- [x] **QF-012 成交容量和部分成交**
  - 引入成交额参与率、滑点随流动性/波动变化、开盘缺口和部分成交。
  - 未成交订单的生命周期、覆盖、过期原因全部可追溯。

## P2：因子、验证和组合算法

- [x] **QF-013 因子缺失治理**
  - 设置必需字段与最低因子覆盖率。
  - 禁止数据稀疏股票仅靠可用因子重新归一后与完整股票同等竞争。
  - 信号保存数据质量分和全部缺失原因。

- [x] **QF-014 行业分类时点化**
  - 历史回测使用当时行业分类；无历史分类时显式限制可回测区间。
  - 统一申万2021口径，避免同一股票多套行业名称混用。

- [x] **QF-015 行业/风格真正中性**
  - 行业基准权重按指数权重或自由流通市值，不再按股票数量近似。
  - 约束行业、市值、Beta、流动性暴露，并报告相对基准偏离。

- [x] **QF-016 完善质量因子**
  - 增加 ROA、现金流质量、应计利润、盈利稳定性、利润率变化。
  - 银行、券商、保险使用独立财务指标，不与普通工业公司混算。

- [x] **QF-017 完善价值因子**
  - 增加 EP、BP、SP、股息率、自由现金流收益率。
  - 亏损企业采用明确分类/惩罚，不把负 PE 简单当缺失后重分权重。

- [x] **QF-018 完善动量、趋势和低风险因子**
  - 研究 12-1、6-1、短期反转、残差动量。
  - 增加 60/120 日波动、Beta、残差波动和最大回撤。
  - 控制动量与趋势重复暴露。

- [x] **QF-019 因子诊断**
  - 按期输出 IC、ICIR、t 值、胜率、衰减、换手、容量及因子相关矩阵。
  - 五档收益必须逐期分组后再做时间序列汇总。
  - 增加 Newey-West/Bootstrap 稳健区间和多重检验提示。

- [x] **QF-020 股票走步和完全留出验证**
  - 将股票策略接入 purged walk-forward、embargo、训练/验证/留出集。
  - 参数只在训练段选择，留出段只允许评估一次。
  - 按年份、牛熊震荡、行业和市值分组检查稳定性。

- [x] **QF-021 风险与成本感知组合优化**
  - 目标：因子预期收益 - 风险惩罚 - 换手惩罚 - 交易成本。
  - 约束单股、行业、风格、跟踪误差、组合波动、ADV参与率和最少持仓数。
  - 输出预期风险、有效持仓数、集中度和压力测试。

- [x] **QF-022 调仓缓冲**
  - 增加持仓保留区、入选/剔除双阈值和最小交易权重，降低排名边界抖动。

- [x] **QF-023 收益归因**
  - 输出选股、行业、风格、现金拖累、费用和滑点贡献。
  - 回测与前向账户使用同一归因实现。

- 公司行为按权益登记、现金应收/到账、送转、现金受限配股、换股合并、
  代码变更、现金收购/退市清算分别处理；原始价用于执行，前复权价仅用于
  因子收益研究。美的电器换股吸收合并和中航电测代码变更使用本地归档的

  成交量参与率、部分成交和订单过期规则。订单逐股保存
  `pending/partially_filled/filled/expired/overridden` 状态和原因。
- 因子快照包含全候选排名、缺失原因、IC/ICIR、Newey-West t 值、块
  Bootstrap 区间、分层收益、衰减、相关矩阵、换手、容量和多重检验提示；

  规范值、异常状态和文件哈希进入治理表，所有降级均进入 API warning。

  42 个交易日模拟和对账是硬门禁。留出评估前还要求 Git 工作区无未提交
  改动，系统证据哈希不能由接口调用者伪造。
