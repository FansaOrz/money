# 量化平台运行与事故响应手册

## 状态、职责和统一处置

本手册适用于值班人、研究负责人、交易负责人和安全负责人。任何 P0/P1 事故
首先冻结自动下单、保留关联 ID 与只读证据，再恢复服务；不得为了恢复界面而
跳过账本、数据或对账门禁。

| 故障 | 检测 | 立即止损 | 恢复与验证 | 主责/通知 |
|---|---|---|---|---|
| 数据延迟/空响应 | deep health、SLA、逐股覆盖 | 停止信号与订单，不沿用旧横截面 | 补采、哈希校验、PIT/覆盖复核后重跑 | 数据值班/研究负责人 |
| 调度失败/重复调度 | 心跳、持久任务、幂等键 | 暂停依赖任务 | 从 checkpoint 恢复，比较单次运行结果 | 平台值班 |
| 数据库锁/磁盘满 | DB 延迟、锁超时、磁盘阈值 | 进入 safe-stop，禁止新写入 | 终止异常事务/扩容，完整性与账本不变量检查 | DBA/平台值班 |
| 账本不平/重复订单 | 三方对账、现金守恒、事件唯一键 | kill switch，撤销开放订单 | 事件回放，双人审批修正，重新对账 | 交易负责人/合规 |
| 券商断线/时钟偏移 | adapter 心跳、NTP 门禁 | 禁止新单，仅允许安全撤单 | 获取权威快照，三方对账，时钟恢复后双人解锁 | 交易值班 |
| 行情异常/涨跌停错误 | 多源差异、价格偏离、交易规则 | 停止受影响证券 | 官方源复核、数据更正审计、重建信号 | 数据值班/交易负责人 |
| API/调度进程退出 | 容器健康、外部 Webhook | 自动重启；交易路径 safe-stop | readiness、迁移、心跳、积压任务复核 | 平台值班 |
| 凭据泄漏 | secret scan、异常调用 | 吊销单一身份/轮换凭据 | 审计访问范围，重发短期凭据 | 安全负责人 |
| 主机/数据库灾难 | 外部监控和备份年龄 | 宣布灾难，禁止交易 | 按灾备手册在隔离环境恢复并校验 | 事故指挥/DBA |

事故指挥负责定级和每 30 分钟状态通报；技术主责负责止损与恢复；记录员保存
时间线、命令输出、告警、审批人和证据哈希。恢复后 2 个工作日内完成无责复盘，
包含根因、影响、探测缺口、修复 owner、截止日期和回归测试。

## 演练检查单

- [ ] 演练人未参与对应功能开发，能只依赖本文定位健康检查和关联 ID。
- [ ] 注入故障后策略进入 safe-stop，外部告警在 SLA 内送达并升级。
- [ ] 恢复使用原幂等键，不产生重复订单、成交或任务。
- [ ] 订单、成交、持仓、现金、净值、基准与券商快照全部对账。
- [ ] 记录开始/恢复时间并与 RTO 比较，记录最后恢复点并与 RPO 比较。
- [ ] 复盘和未解决项进入跟踪清单；未关闭 P0/P1 时不得解除门禁。
